# **App Name**: Global Gastronomy Guide

## Core Features:

- Recipe Card Display: Display recipe cards with image previews, dish name, and region/country of origin.
- Search and filter for recipe cards: search recipe cards with regex dish name and have region/country filters to search all recipe cards belonged to that area
- Detailed Recipe View: Provide a dedicated page for each recipe including a title, dish image, ingredients list and image for each ingredient, preparation instructions, and additional notes.
- Ingredient-Based Recipe Search: Implement a filterable recipe search based on ingredients.
- Voice/Image Assisted Recipe Discovery: Allow users to search by voice command or image for available recipes.

## Style Guidelines:

- Primary color: Burnt Sienna (#E9724C), a warm and inviting hue evoking a sense of home cooking and comfort.
- Background color: Light beige (#F5F5DC), providing a neutral backdrop to ensure readability and focus on the food imagery.
- Accent color: Olive Green (#A9A471), an earthy tone to complement the primary color, inspired by natural, fresh ingredients.
- Body text: 'PT Sans', a humanist sans-serif offering a modern yet approachable aesthetic, ensuring readability for recipe details.
- Headline font: 'Playfair', a modern serif with high contrast for an elegant feel; if longer text is anticipated, use this for headlines and 'PT Sans' for body
- Utilize clean and modern icons, focused on user actions and search filters. Consider the use of outline icons with rounded corners.
- Employ a card-based layout for the recipe listing and a clear linear layout for the recipe details.
- Implement subtle transition animations when displaying recipe details.
